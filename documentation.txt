==============================================================================
DOCUMENTATION TECHNIQUE - PROJET DJANGO / ANGULAR / GRAPHQL
==============================================================================

Bienvenue sur le projet ! 
Cette documentation détaille le workflow standard pour ajouter une nouvelle fonctionnalité (Module/Entité) en respectant l'architecture "Modulaire & Scalable".

PRÉ-REQUIS
----------
- Backend : Python 3.10+, Django, Graphene
- Frontend : Node 18+, Angular 18+, Apollo GraphQL
- Outils : Script `./snake` (Wrapper manage.py)

==============================================================================
WORKFLOW DE DÉVELOPPEMENT (ÉTAPE PAR ÉTAPE)
==============================================================================

1. BACKEND : SCAFFOLDING & MODÉLISATION
---------------------------------------
L'outil `snake` permet de générer la structure de base.

a) Générer les fichiers Backend
   Commande : ./snake craft scaffold <NomEntite> <NomApp>
   Exemple  : ./snake craft scaffold Evenement profilmanagement

b) Définir le Modèle
   Fichier : apps/<app>/models/<entite>.py
   Action  : Ajoutez vos champs (CharField, DateTimeField, etc.).

c) CORRECTION CRITIQUE : IMPLÉMENTER LA PAGINATION
   Le scaffold génère par défaut une requête "Liste simple". Pour les listes paginées du frontend, il faut modifier la Query.
   
   Fichier : apps/<app>/graphql/Queries/<entite>_query.py
   
   Modèle à suivre :
   ------------------------------------------------------------
   from apps.core.graphql.Types.paginated_type import get_paginated_type
   
   <Entite>PaginatedType = get_paginated_type(<Entite>Type)

   class <Entite>Query(graphene.ObjectType):
       <entites> = graphene.Field(
           <Entite>PaginatedType,
           search=graphene.String(),
           page=graphene.Int(default_value=1),
           page_size=graphene.Int(default_value=10)
       )

       def resolve_<entites>(root, info, search=None, page=1, page_size=10, **kwargs):
           queryset = <Entite>.objects.filter(is_deleted=False).order_by('-created_at')
           
           if search:
               queryset = queryset.filter(Q(nom__icontains=search)) # Adapter le filtre

           # Utilisation de l'utilitaire de pagination (DRY)
           from apps.core.utils.pagination import paginate_queryset
           paginated_data = paginate_queryset(queryset, page, page_size)

           return <Entite>PaginatedType(**paginated_data)
   ------------------------------------------------------------

d) Migrations
   Commande : ./snake craft automigrate

e) Configuration du Menu (Navigation)
   Ne PAS utiliser de script temporaire.
   Fichier : apps/core/management/commands/seed_navigation.py
   Action  : Ajoutez votre page dans la structure MODULE_STRUCTURE.
   Commande : ./snake seed:navigation (ou python3 manage.py seed_navigation)

------------------------------------------------------------------------------

2. FRONTEND : GRAPHQL & CODEGEN
-------------------------------
Nous n'écrivons PAS de requêtes GraphQL "en dur" (inline) dans les composants. Nous utilisons la génération de code.

a) Définir la Query
   Fichier : frontend/src/app/features/<module>/graphql/profil.graphql (ou fichier dédié)
   Action  : Ajoutez les Fragments et les Queries (GetById et GetAll).
   
   Exemple :
   query GetAllEvenements($search: String, $page: Int, $pageSize: Int) {
     evenements(...) { ... }
   }

b) Générer le code TypeScript
   Le générateur a besoin d'un Token JWT valide pour l'introspection.
   
   1. Récupérer un Token (si besoin, via script ou login).
   2. Lancer la génération :
      export JWT_TOKEN="<votre_token>" && npm run codegen
   
   Résultat : De nouveaux services sont créés dans `frontend/src/app/graphql/generated.ts`.

------------------------------------------------------------------------------

3. FRONTEND : COMPOSANTS SERVICIELS
-----------------------------------

a) Service Angular
   Créez un service qui étend `BaseService` et injecte le service généré par Codegen.
   
   Fichier : frontend/src/app/features/<module>/services/<entite>.service.ts
   Exemple :
   ------------------------------------------------------------
   @Injectable({ providedIn: 'root' })
   export class EvenementService extends BaseService {
     endpoint = 'evenement';
     private generatedGQL = inject(GetAllEvenementsGQL); // Généré par Codegen

     getQuery() {
       return this.generatedGQL.document;
     }
   }
   ------------------------------------------------------------

b) Composant Liste
   Créez le composant qui étend `BaseListComponent`.
   
   Fichier : frontend/src/app/features/<module>/components/<entite>-list/...
   Exemple :
   ------------------------------------------------------------
   export class EvenementListComponent extends BaseListComponent<any> {
     service = inject(EvenementService);
     query = this.service.getQuery(); // Récupération propre de la query
     responseKey = 'evenements';
     // ...
   }
   ------------------------------------------------------------

c) Enregistrement de la Route
   Fichier : frontend/src/app/core/routing/component.registry.ts
   Action  : Mappez l'URL (définie dans seed_navigation) vers le composant lazy-loaded.

==============================================================================
RÉSUMÉ DES COMMANDES UTILES
==============================================================================

# Backend
./snake craft scaffold <Entite> <App>   # Créer une entité
./snake craft automigrate               # Appliquer les migrations
python3 manage.py seed_navigation       # Mettre à jour le menu

# Frontend
npm start                               # Lancer le serveur de dev
npm run codegen                         # Générer les types GQL (nécessite JWT_TOKEN)

==============================================================================
CONVENTIONS
==============================================================================
- Nommage : PascalCase pour les Classes/Types, camelCase pour les champs API.
- Architecture : Modèle > Service > Controller > GraphQL (Back) -> Generated Service > Component (Front).
- Pagination : Toujours implémenter `PaginatedType` pour les listes.
